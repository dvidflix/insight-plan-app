Project database in the browser: folder test

Use Edge or Chrome. Do the four steps in order. Nothing leaves this computer.

1. Choose the project folder

Pick a folder, for example one inside your OneDrive. The browser will ask permission to edit files in it.

2. Create the database

Builds the app's database and imports a programme of 50,000 activities, in memory.

3. Save it into the folder

Writes insight-plan-PROOF-TEST.db into the folder you chose. Afterwards look in the folder (and in OneDrive) to see the file appear.

4. Forget it, then open it again from the folder

Throws away the in-memory copy and reads the file back from the folder.
