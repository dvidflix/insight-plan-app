Keyboard shortcuts

Shortcuts act on what is showing and are ignored while you type in a field. Ctrl also means Cmd on a Mac where it says so.

Everywhere

KeysWhat it does
Ctrl+Alt+P / Q / U / WGo to Inputs / Models / Programmes / 4D Sequencing
Ctrl+Tab, Ctrl+Shift+TabNext / previous tab at the top
Alt+Page Down, Alt+Page UpNext / previous tab (use these in a normal browser tab, which keeps Ctrl+Tab for itself)
Ctrl+Alt+9Show or close the Viewpoints panel (Models and 4D Sequencing)
EscClose a menu or cancel what you are doing
Enter / EscAccept / cancel a name you are typing

The 3D view

These work on the number pad and on the number row. Ctrl with a number works on the number pad only (the browser keeps Ctrl+number for its own tabs).

KeysWhat it does
1 / Ctrl+1Front / back view
3 / Ctrl+3Right / left view
7 / Ctrl+7Top / bottom view
9The opposite view: a front, back, left, right, top or bottom view goes to its opposite; any other view goes round 180° about the vertical, keeping its height
5Switch between perspective and orthographic
4 / 6Turn the view 15° left / right
8 / 2Turn the view 15° up / down
Ctrl+4 / 6 / 8 / 2Slide the view left / right / up / down
Numpad + / Numpad −Zoom in / out
Numpad .Fit the selection (everything when nothing is selected)
HomeFit everything

Selecting and measuring

KeysWhat it does
ClickSelect an object
Ctrl+clickAdd an object to the selection, or take it out
Drag (Box select)Select what the rectangle holds: left to right for objects fully inside, right to left for objects it touches. Ctrl or Shift adds
EscCancel the measurement you are making
Delete, BackspaceRemove the measurement you are making, the last point of the Point tool, or the section you picked

Walkthrough

Start it from the toolbar, then:

KeysWhat it does
W A S D (or ↑ ↓ for forward and back)Move
E, Space, Page UpUp
Q, C, Page DownDown
← →Turn
ShiftFaster
EscLeave the walkthrough

Compare slider

With the compare slider on, click it and use ← → to move it a step, Home / End to put it at either edge.

4D timeline

KeysWhat it does
SpacePlay or pause
Ctrl+Alt+3Play or pause (works from anywhere)
Ctrl+Alt+0Go to the start
Ctrl+Alt+4Go to the end
→ / ←, Ctrl+. / Ctrl+,One step forward / back (the Step in the status bar)
Ctrl+Alt+5 / Ctrl+Alt+6A longer / shorter Step
Ctrl + wheel over the timeline barZoom the bar

The same Ctrl+Alt+3, 0 and 4 play, rewind and fast-forward the sets in the Sets player.

Lists and tables

Picking rows

KeysWhat it does
ClickPick one row
Ctrl+clickAdd or remove a row
Shift+clickPick every row from the last one picked to this one
Shift+Ctrl+clickAdd that range to what is picked (in the programme tables)
↑ / ↓Move to the previous / next row

Selection tree (Models and 4D, Structure / Types / Layers)

KeysWhat it does
→ / ←Open a row (or step into it) / close it (or go to its parent)
Shift+↑ / Shift+↓Extend the picked rows
Home / EndFirst / last row
SpaceHide the picked rows' objects, or show them when any is hidden (the eye does the same)

Sets, Models list, Colour values

KeysWhat it does
↑ / ↓Previous / next set, model or colour value
SpaceTurn the selected ones on or off in 3D (their eye)
Ctrl+SSave the current selection as a set
Shift+click, Ctrl+clickPick several

Gantt and Programme tables

KeysWhat it does
↑ / ↓, Page Up / Page DownMove the selected activity
EnterBring the selected activity's bar into view
Alt+S / Alt+FLink the picked activities Start to Start / Finish to Start
Ctrl + wheelZoom the time scale

Scenarios pour order

KeysWhat it does
Alt+↑ / Alt+↓Move the picked pours up / down
Alt+S / Alt+FMake the picked pours start together (SS) / one after the other (FS)
Ctrl+Z / Ctrl+YUndo / redo

Timelines grid (like a spreadsheet)

KeysWhat it does
Arrow keys, Tab, Shift+TabMove between cells
Enter, F2Edit the cell (Enter then goes down a row, Tab across)
EscStop editing
Delete, BackspaceClear the picked cells
Ctrl+C, Ctrl+X, Ctrl+VCopy, cut, paste (also with Excel)
Ctrl+ZUndo
Ctrl + wheelZoom the time axis

Other lists

KeysWhat it does
↑ / ↓Move through the clashes in the Clash panel
Ctrl + wheel over a Resources graphZoom the graph
