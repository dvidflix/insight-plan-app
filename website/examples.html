Examples

Where it goes further than ordinary tools

Specific things you can do on day one, grouped by the job they help with.

Sets that do the work

Selection, search and phasing, in one set list.

Selection sets become search sets

Pick the properties that identify the objects (the Pour ID, say), see how many it finds, and create a search set. It then follows the model when it is re-converted or revised. Do it for one set or for a whole folder at once.

Search sets run again on whatever is loaded

Conditions on any property: is any of (with value counts), contains, starts or ends with, regex, greater or less than, between, has or has no value. Match all or any.

Freeze a search as a selection set

Keep today's matches as a fixed list, held by model name and GlobalId so it survives reloading or re-converting a model.

Play a folder of sets like phasing

The sets in a folder become steps. Play, pause, step back and forward or jump to the start or end, on the same shortcuts as the 4D timeline. Each step shows the sets so far and hides the rest.

Eyes, collections and the space bar

Each set and folder has an eye that hides or shows its objects in 3D. Select several sets with Shift or Ctrl and toggle them together with the space bar. Choose which buttons show on each row.

Step through sets with the arrow keys

Walk a list of sets one at a time to review each group of objects in turn.

Fix the model, not just report it

Model checks that repair what they find.

IDS checks with linked patches

Check against IDS files, then fix the failures. A patch can reclassify elements from a property, set a property value, pad numbers with leading zeros, or name elements after their pour ID.

Rebuild the spatial structure

One site, a building per unit, a storey per level at the right elevation, each element contained in its storey, storeys in level order.

Merge buildings that an export split

Several exported zones become one building named properly, with matching storeys merged and the emptied ones removed.

Preview before you apply

See what a patch would change and what it leaves alone. Applying writes a new _FIXED IFC with a change log and loads it in place, keeping its placement. The original file is never changed.

Rules IDS cannot express

Custom rules count things ("only one building") and compare one value with another ("the name equals the pour ID").

Edit properties on the selection

Queue several property edits, then write them in one go. Shared values are copied, never changed in place, so other elements keep theirs.

Select all failing

Jump from a failed check straight to the offending objects in 3D, or export every failing element to CSV.

Topics: issues that live in the model

BCF issues you can place, discuss and exchange. Topics are an experimental feature: switch them on in the settings.

BCF issues with comments

Raise a topic with a type (issue, clash, request, remark, fault or inquiry), a status, a priority and an assignee, then add comments, each with its own viewpoint of the model.

Put the issue where it is

Give a topic a point in the model and it shows as a marker in the 3D view. Click the marker to open the topic.

Tie an issue to the programme

A topic can start and finish with activities of the programme, and shows in 4D only while its dates are on, so the issue appears at the right point in the sequence.

Import and export BCF

Bring in BCF files from BIMcollab, Solibri or Revit, and export your own. The start, location and linked tasks travel as ordinary labels, so other BCF tools show them too.

Find and filter

Search topics, filter by status, and choose which buttons show on each row.

Clashes and touching

Geometry relationships, kept ready.

Within a model, across models

Every model against itself and against every other, in the background, stored in the project so it is ready next time.

What sits below, above or beside

Select the elements touching a selection in a direction, and click again to go one step further, for support and sequence questions.

Exact or quick

Test the real triangles, or bounding boxes only. Set the tolerance for what still counts as contact.

Align first, then check

Place each model in project axes, with presets, and clashes use that placement.

Seeing the sequence

4D that you can shape and share.

Link by rules

Pair a task field with an object property. Live counts show how many tasks and objects are linked, and what is left over.

Appearance profiles

Install, remove or maintain, with colour and opacity per stage and growth animations: drop, slide in, bottom to top, lift up, slide away.

Planned beside actual

Split the view to compare planned and actual, or two projects with the slider.

Labels and tags

A Navisworks-style date label on a 3-by-3 grid, and callouts on objects built from task and object properties.

Video made in the app

Step the timeline over a date range and record PNG images or an MP4, encoded in the browser, with label, tags, progress bar and a tasks table.

Navisworks both ways

Export a TimeLiner pack from the link groups, and import steps from a TimeLiner CSV.

Saved views and fly-throughs

Camera, visibility, colours, section planes and style saved together, plus camera fly-throughs on a smooth path.

Programme analysis

What the scheduler alone does not tell you.

Resource levelling

Demand per trade against capacity, with the before-levelling total as a grey line. Level within float or allow a later finish, then add the result as a new programme to compare or play in 4D.

Look-ahead and PPC

Everything starting, finishing or running through the next weeks, and Percent Plan Complete with reasons for each miss.

Monte Carlo risk

Chance of finishing by a date, P50, P80 and P90, and each activity's criticality, with calendars and logic respected.

Driving path and curtain

Show the chain that fixes an activity's start, and fade the other rows back instead of removing them.

Delay and drag

Compare baseline and current to see delay events and critical-path drag.

DCMA and beyond

The 14-point assessment plus extra checks, with thresholds you can edit.

Bulk edit with preview

Rule-based changes to many activities, a before and after list, apply, and undo the last edit.

Anonymise to share

Consistent neutral labels for names, codes and resources, and an option to shift every date.

Works with your tools

Alongside P6 and MS Project, or on its own.

P6 in, P6 out

Read XER and XML, then write XER and XML back and import them into P6.

Live read-only P6 databases

Read a P6 Professional database directly, with nothing ever written to it.

MS Project programmes

Read MS Project XML with tasks and links, then use 4D, resources and checks on it.

Spreadsheet programmes

Excel or CSV with names and dates becomes a programme, matched by flexible column headings.

Models without a programme

Clash checks, IDS patches, sets and the set player need no programme at all.

Programmes without a model

Analysis, levelling, risk, look-ahead and PPC need no model.

Data you can use anywhere

Open formats, no lock-in.

One SQLite file per project

Programmes are stored in Primavera's own tables and columns, so they open in any SQLite tool and read as XER data.

Live, read-only P6 databases

Link a P6 Professional standalone database and read its projects each time, without ever writing to it.

Add your own columns

Push model elements to SeaTable, add columns there and pull them back as custom fields.

A data table over the model

Columns, filters, groups, sort and colour on any property, with totals and subtotals, over 100,000 rows, saved as presets.

Twin models

Pair two models that share geometry but not properties, and show both sets of properties side by side.

Layouts and presets

Save a table, Gantt or Explorer setup by name and come back to it.

Built for the working day

Small things that save an hour.

Duplicate in a new tab

Open a second copy with the same models and programmes.

Colour-blind safe palette

Gantt, network and status colours that stay apart for common colour vision differences.

Section, measure, coordinates

Section planes, length, area, angle and volume, and point coordinates in project axes copied to the clipboard.

Storey slide

Pull storeys apart vertically to see inside a building.

Settings travel

Export the whole configuration and import it on another machine.

A wiki that ships with it

The guide is in the app, and your team can add pages and paste images and videos.
