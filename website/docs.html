Start here

Getting started

Insight Plan links a construction programme to a 3D model so you can see the build in time, check the model, and plan the work.

Inputs

Everything you work with comes in here: models, programmes and the project folder.

Models

Models

The 3D viewer, with a toolbar over the model and a side pane with the tools. For the side pane tabs see Models: the side pane.

Models: the side pane

The tabs beside the 3D view. Drag the edge of the pane to resize it.

Programmes

Programmes

Your P6 programmes, in the view you choose from the Views list at the top of the page. Several programmes can be open together. The planning tools have their own page: Planning tools.

Planning tools

Choose these from the Views list on the Programmes page.

Programme and model together

4D Sequencing

Link programme activities to model objects, then play the build over time. You need a model and a programme loaded first (see Inputs).
