System requirements

  • Chrome or Edge, a recent version
  • A secure (HTTPS) address for the app: ours, or your own intranet
  • 16 GB of memory recommended for large models
  • No internet connection needed to run

Data handling

Programmes, models and results are read and saved in the project folder you choose, on your computer. The app does not send them anywhere and has no account or telemetry. A third-party software list ships with each release.

Frequently asked

Which programme formats can it read?

Primavera P6 XER and XML, MS Project XML (File > Save As > XML), and Excel and CSV. It writes P6 XER and XML, and Excel. MS Project .mpp files are not read directly: save them as XML first.

Which model formats?

IFC, and FRAG (an already converted model). glTF can be added as site context. Models are converted and drawn in your browser, on your own machine.

Can it be used for safety-related decisions?

No. It is a planning and review tool. It does not replace your safety case or approved engineering processes.

How do updates work?

A new version is picked up the next time the app is opened, from wherever it is hosted. If your organisation hosts it on its own intranet, your IT team decides when a new version goes live.

Will there be a multi-user, cloud version?

The weekly planning module for site teams is in development and is designed for tablets and several users at once. The planning workbench stays offline.
