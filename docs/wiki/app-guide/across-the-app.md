# Across the app

- **Side pane** — full window height, icon tabs as tall as the top bar, resizable, hideable; **Settings** is its last tab.
- **Settings** — export / import the whole configuration as one JSON file (link groups, appearance profiles, programmes, model references, every saved view setting; model geometry is not included), full screen on start, table header wrapping, selection colour, floor-plan range.
- **Duplicate in a new tab** (top-right) — opens the app again with the same models and programmes, e.g. for a second screen. The new tab gets them from this one (models as `.frag`, so nothing is re-converted); the two then work independently.
- **Full screen on start** — the app goes full screen on the first click or key press (browsers don't allow it on load); can be turned off in Settings.
