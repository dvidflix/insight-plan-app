# 4D Sequencing

Link programme activities to model objects and play the build.

- **Link Groups** — which tasks go with which objects: task filters (activity code, UDF, code / name), object filters (any property, case-sensitive or not, ignorable), and **match rules** pairing a task field with an object property (AND / OR clusters). Live counts of linked tasks and objects.
- **Appearance Profiles** — how linked objects look before, during and after their task: *install*, *remove* or *maintain*; colour and opacity per stage; **growth** animation in (drop, slide in, bottom-to-top) and out (lift up, slide away).
- **Timeline** in the status bar — play / step / scrub by hour, day, week, month or year over a year-banded track; *Jump to date*; planned or actual dates.
- **Colour modes** per view — appearance profiles, original colours, or by property.
- **Split view** — e.g. planned on one side and actual on the other, or two projects compared with the slider.
- **Search sets** — the same search and selection sets as on the Models page (including imported Steps), to select and isolate objects while sequencing; the Scenarios tab's **From steps** orders pours by the Steps sets.
- **Label** — an on-screen date label from a Navisworks-style template, placed on a 3×3 grid; **tags** — callouts on objects built from task fields and object properties.
- **Tasks** panel — the tasks active at the current date, tinted with their stage colour.
- **Export** — **images & video**: step the timeline over a date range and record each step (3D views, label, tags, an optional progress bar and tasks table) to PNG files or an MP4 encoded in the browser (WebCodecs H.264). **Navisworks TimeLiner**: search sets + TimeLiner CSV + instructions, from the Link Groups.
