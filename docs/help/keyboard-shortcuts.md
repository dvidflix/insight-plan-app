# Keyboard shortcuts

Shortcuts act on what is showing and are ignored while you type in a field. **Ctrl** also means **Cmd** on a Mac where it says so.

## Everywhere

| Keys | What it does |
| --- | --- |
| **Ctrl+Alt+P** / **Q** / **U** / **W** | Go to Inputs / Models / Programmes / 4D Sequencing |
| **Ctrl+Tab**, **Ctrl+Shift+Tab** | Next / previous tab at the top |
| **Alt+Page Down**, **Alt+Page Up** | Next / previous tab (use these in a normal browser tab, which keeps Ctrl+Tab for itself) |
| **Ctrl+Alt+9** | Show or close the Viewpoints panel (Models and 4D Sequencing) |
| **Esc** | Close a menu or cancel what you are doing |
| **Enter** / **Esc** | Accept / cancel a name you are typing |

## The 3D view

These work on the number pad and on the number row. **Ctrl** with a number works on the number pad only (the browser keeps Ctrl+number for its own tabs).

| Keys | What it does |
| --- | --- |
| **1** / **Ctrl+1** | Front / back view |
| **3** / **Ctrl+3** | Right / left view |
| **7** / **Ctrl+7** | Top / bottom view |
| **9** | The opposite view: a front, back, left, right, top or bottom view goes to its opposite; any other view goes round 180° about the vertical, keeping its height |
| **5** | Switch between perspective and orthographic |
| **4** / **6** | Turn the view 15° left / right |
| **8** / **2** | Turn the view 15° up / down |
| **Ctrl+4** / **6** / **8** / **2** | Slide the view left / right / up / down |
| **Numpad +** / **Numpad −** | Zoom in / out |
| **Numpad .** | Fit the selection (everything when nothing is selected) |
| **Home** | Fit everything |

### Selecting and measuring

| Keys | What it does |
| --- | --- |
| **Click** | Select an object |
| **Ctrl+click** | Add an object to the selection, or take it out |
| **Drag** (Box select) | Select what the rectangle holds: left to right for objects fully inside, right to left for objects it touches. **Ctrl** or **Shift** adds |
| **Esc** | Cancel the measurement you are making |
| **Delete**, **Backspace** | Remove the measurement you are making, the last point of the Point tool, or the section you picked |

### Walkthrough

Start it from the toolbar, then:

| Keys | What it does |
| --- | --- |
| **W** **A** **S** **D** (or **↑** **↓** for forward and back) | Move |
| **E**, **Space**, **Page Up** | Up |
| **Q**, **C**, **Page Down** | Down |
| **←** **→** | Turn |
| **Shift** | Faster |
| **Esc** | Leave the walkthrough |

### Compare slider

With the compare slider on, click it and use **←** **→** to move it a step, **Home** / **End** to put it at either edge.

## 4D timeline

| Keys | What it does |
| --- | --- |
| **Space** | Play or pause |
| **Ctrl+Alt+3** | Play or pause (works from anywhere) |
| **Ctrl+Alt+0** | Go to the start |
| **Ctrl+Alt+4** | Go to the end |
| **→** / **←**, **Ctrl+.** / **Ctrl+,** | One step forward / back (the Step in the status bar) |
| **Ctrl+Alt+5** / **Ctrl+Alt+6** | A longer / shorter Step |
| **Ctrl + wheel** over the timeline bar | Zoom the bar |

The same **Ctrl+Alt+3**, **0** and **4** play, rewind and fast-forward the sets in the Sets player.

## Lists and tables

### Picking rows

| Keys | What it does |
| --- | --- |
| **Click** | Pick one row |
| **Ctrl+click** | Add or remove a row |
| **Shift+click** | Pick every row from the last one picked to this one |
| **Shift+Ctrl+click** | Add that range to what is picked (in the programme tables) |
| **↑** / **↓** | Move to the previous / next row |

### Selection tree (Models and 4D, Structure / Types / Layers)

| Keys | What it does |
| --- | --- |
| **→** / **←** | Open a row (or step into it) / close it (or go to its parent) |
| **Shift+↑** / **Shift+↓** | Extend the picked rows |
| **Home** / **End** | First / last row |
| **Space** | Hide the picked rows' objects, or show them when any is hidden (the eye does the same) |

### Sets, Models list, Colour values

| Keys | What it does |
| --- | --- |
| **↑** / **↓** | Previous / next set, model or colour value |
| **Space** | Turn the selected ones on or off in 3D (their eye) |
| **Ctrl+S** | Save the current selection as a set |
| **Shift+click**, **Ctrl+click** | Pick several |

### Gantt and Programme tables

| Keys | What it does |
| --- | --- |
| **↑** / **↓**, **Page Up** / **Page Down** | Move the selected activity |
| **Enter** | Bring the selected activity's bar into view |
| **Alt+S** / **Alt+F** | Link the picked activities Start to Start / Finish to Start |
| **Ctrl + wheel** | Zoom the time scale |

### Scenarios pour order

| Keys | What it does |
| --- | --- |
| **Alt+↑** / **Alt+↓** | Move the picked pours up / down |
| **Alt+S** / **Alt+F** | Make the picked pours start together (SS) / one after the other (FS) |
| **Ctrl+Z** / **Ctrl+Y** | Undo / redo |

### Timelines grid (like a spreadsheet)

| Keys | What it does |
| --- | --- |
| **Arrow keys**, **Tab**, **Shift+Tab** | Move between cells |
| **Enter**, **F2** | Edit the cell (**Enter** then goes down a row, **Tab** across) |
| **Esc** | Stop editing |
| **Delete**, **Backspace** | Clear the picked cells |
| **Ctrl+C**, **Ctrl+X**, **Ctrl+V** | Copy, cut, paste (also with Excel) |
| **Ctrl+Z** | Undo |
| **Ctrl + wheel** | Zoom the time axis |

### Other lists

| Keys | What it does |
| --- | --- |
| **↑** / **↓** | Move through the clashes in the Clash panel |
| **Ctrl + wheel** over a Resources graph | Zoom the graph |
