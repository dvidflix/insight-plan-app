# Getting started

Insight Plan links a construction programme to a 3D model so you can see the build in time, check the model, and plan the work.

## The first start

1. **Licence key.** Paste the key you were given and press **Activate**. It is checked on this computer and kept in this browser, so you only enter it once. A warning shows in the last 30 days before it ends.
2. **Choose where the project lives.** The app asks you to open your project: press **Choose folder…** (it is also in **Inputs**, under the project database). Pick a folder on your computer or in OneDrive. The browser asks permission once. Use **Chrome or Edge** for this.
   The app keeps your project in that folder as ordinary files, so you can back it up and nothing is lost if the browser clears its data.
3. **Add your files.** Drop an IFC model and a P6 programme (`.xer` or `.xml`) on the Inputs page.
4. **Link them.** In **4D Sequencing**, make a link group that tells the app which tasks go with which objects, then press play.

## The tabs

| Tab | What it is for |
| --- | --- |
| [Inputs](inputs.md) | Load models and programmes, choose the project folder |
| [Models](models.md) | The 3D viewer: look at, measure, search and check the model |
| [Programmes](programmes.md) | The activities table, Gantt, resources, checks and planning tools |
| [4D Sequencing](4d-sequencing.md) | Link tasks to objects and play the build over time |
| Help | This guide |

Use the **Settings** tab (last tab of the side pane) to change how the app looks and behaves: see [Settings and tips](settings-and-tips.md).

## Install it and work offline

In Chrome or Edge, press **Install** in the address bar (a small icon at its right end). The app then opens from your desktop like any program, and it works with no internet. Your project stays in the folder you chose.

## Where to look when you are stuck

- [Your data and saving](your-data.md): where files go, what is saved when, what is not in this edition.
- Hover over a button: most have a tooltip, and the small **i** marks in Settings explain each option.
