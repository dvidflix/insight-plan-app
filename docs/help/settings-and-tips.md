# Settings and tips

**Settings** is the last tab of the side pane.

## What you can change

| Section | Use it for |
| --- | --- |
| **Project database** | The project folder and its database |
| **Exports (XML / XER)** | What goes into the programme files you download |
| **Window** | Full screen on start, which tabs show, the status bar |
| **Experimental features** | Switch on tools that are still being tried out (listed in [Planning tools](planning-tools.md)) |
| **Tables** | How table headers wrap and similar table options |
| **Appearance** | The accent colour palette (Standard green, Ocean, Teal, Violet, Rose, Amber, Graphite) |
| **Accessibility** | A colour-blind safe palette that swaps green and red for blue and orange |
| **4D timeline** | How the 4D timeline looks and plays |
| **Preferences** | Export and import all your settings as one file |

Hover over the small **i** marks for what each option does.

## Moving settings between computers

**Preferences** exports your whole set-up as one file: link groups, appearance profiles, which programmes and models were loaded, and every saved view setting. Import it on another computer. Model geometry is not included, so load the models again from Inputs. After an import, the files it expects are listed until you load them.

## Second screen

**Duplicate in a new tab** (top right) opens the app again with the same models and programmes, for a second screen. The two then work independently.

## Full screen

The app goes full screen on your first click or key press, because browsers do not allow it on load. Turn it off in **Window**.

## Tips

- **Ctrl + click** adds to a selection in 3D and in lists.
- **Hover** over toolbar buttons for what they do.
- **Search** boxes in tables and lists filter as you type.
- Drag the edge of a side pane to **resize** it. Most panes can be hidden.
- Save **layouts** for the Table and Gantt, **views** for the 3D model and **presets** for the data table, so you can return to a set-up in one click.
